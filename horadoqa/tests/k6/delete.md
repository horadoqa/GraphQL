# Delete User

- Ler ids.csv antes do teste.
- Ignorar o cabeçalho id.
- Distribuir os IDs entre os VUs/iterações.
- Evitar que o mesmo ID seja usado por múltiplas iterações.
- Medir duração, sucesso e erros.

- Parar naturalmente quando todos os IDs forem consumidos.
